# Jeenal Shah — portfolio

[Visit the website](https://jeenal4801.github.io/)

This repository hosts the generated GitHub Pages website. Its HTML language label describes the published build, not the full application stack.

The application uses **React and TypeScript** for the interface and animated canvas graphics, **Flask-RESTful** for Python APIs, **Django ORM and migrations** for database access, **PostgreSQL on Neon** for persistent portfolio data, **Redis** for shared AI request limits, and **Gemini** for the profile assistant.

The Python service runs on Render; GitHub Pages serves the frontend. Profile content loads from the Python API, with a prerendered public snapshot for fast display and backend cold starts. The separate source repository is private. No server credentials or private source history are included here.
